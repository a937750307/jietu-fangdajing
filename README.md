# 截图放大镜

一个纯前端的图片标注工具，用于给截图添加放大镜聚焦效果：背景虚化、局部高清放大，并加上可自定义的镜框。所有图片处理都在浏览器本地完成，图片不会上传到任何服务器。

## 功能

- **载入图片**：点击「选择图片」、点击「剪贴板」按钮、`Ctrl + V` 粘贴，或直接把图片拖到右侧区域
- **移动镜片**：在图片上点击或拖动，即可改变放大镜位置
- **镜片形状**：圆形、圆角方形、横版长条、竖版长条
- **可调参数**：
  - 放大镜大小：8% ~ 100%（相对图片宽度）
  - 放大倍数：1.2× ~ 6×
  - 背景虚化程度：0 ~ 30
  - 背景虚化颜色及浓度：0% ~ 100%
  - 镜框颜色及粗细：0 ~ 50
- **一键还原**：「恢复默认设置」重置全部参数
- **导出**：按图片原始分辨率导出 PNG

## 文件结构

```
.
├── index.html   # 页面结构
├── style.css    # 样式（极简风格、响应式布局、备案信息）
└── app.js       # 交互逻辑与 Canvas 绘制
```

三个文件需放在同一目录下，无需构建工具、无需后端、无第三方依赖。

## 使用方式

直接用浏览器打开 `index.html` 即可。

如果需要使用剪贴板按钮读取图片（而非 `Ctrl + V`），建议通过本地服务器访问，例如：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。剪贴板 API 在 `localhost` 或 HTTPS 环境下可用，且需要浏览器授权。

## 实现说明

- 使用两个离屏 Canvas：一张缓存「虚化 + 染色」后的底图，另一张在其上合成镜片。调整参数时只重绘必要的部分，响应更快。
- 导出时按图片原始像素尺寸重新渲染，不会因页面预览缩放而损失清晰度。
- 长条镜片会自动限制尺寸，避免超出图片范围。
- 使用了 Canvas 滤镜、`roundRect`、Clipboard API 等现代浏览器特性，推荐使用较新版本的 Chrome / Edge / Firefox / Safari。
